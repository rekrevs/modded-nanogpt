# T-0001: Fine-tune on Shakespeare for better text generation

**Status**: READY
**Phase**: —

## Context
The 16K-step model trained on FineWeb achieves good perplexity (val_loss 3.23) but produces incoherent text with 84% probability assigned to `<|endoftext|>`. Following Karpathy's original nanoGPT approach, fine-tuning on Shakespeare should produce more coherent, entertaining text generation.

## Acceptance Criteria
- [ ] Shakespeare dataset prepared and tokenized
- [ ] Fine-tuning script created for modded-nanogpt architecture
- [ ] Model fine-tuned on Shakespeare corpus
- [ ] Generated text is recognizably Shakespeare-like (coherent phrases, period-appropriate vocabulary)
- [ ] Model no longer immediately produces `<|endoftext|>`
